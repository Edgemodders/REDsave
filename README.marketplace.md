# REDsave

A save game manager for Cyberpunk 2077, in VS Code. **Preview:** being built.

- **Find any save** by its title, quest, place, date, lifepath, V's body and voice, level, Street Cred, difficulty, playthrough, game version and Phantom Liberty.
- **Loadouts:** keep sets of saves outside the game's save folder and swap one in before you play. Nothing is deleted.
- **Titles of your own** for saves.

REDsave reads saves from `Saved Games\CD Projekt Red\Cyberpunk 2077` in your user folder, where Steam, GOG and Epic copies of the game save. Set another folder with **REDsave: Saves Path** in the settings.
